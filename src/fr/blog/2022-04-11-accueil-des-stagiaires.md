# 🗓️ 2022-04-11 — Accueil de stagiaires en licence informatique

Le 11 avril 2022, nous accueillons trois stagiaires de la licence informatique
de La Rochelle pour développer la plateforme
[**GALACTIC**](https://www.thegalactic.org/) :

* Éléonore Thonneau : gestion des caractéristiques d'appartenance floue ;
* Clément Ehlinger : génération d'installateurs pour les principaux systèmes
  d'exploitation ;
* Kevin Voisin : caractéristique de plugin par spécification d'un chemin de
  type sélecteur CSS ou XPath.
